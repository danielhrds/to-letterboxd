# Atribuições

To Letterboxd é independente do Letterboxd, do IMDb e do TMDB. As marcas e os respectivos catálogos pertencem aos seus titulares.

This product uses the TMDB API but is not endorsed or certified by TMDB.

O logotipo TMDB em `assets/tmdb.svg` é a versão azul quadrada criada pelo TMDB. A extensão distribui uma cópia local para mostrar a atribuição sem solicitar imagens ao serviço.
